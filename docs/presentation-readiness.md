# 成果發表驗收計畫｜v0.3.2

本輪新增 P01–P14 展示驗收案例，僅使用獨立合成素材。此為補充技術測試，不取代原訂 [50 組研究案例](testing/50-cases.md) 或 [使用者研究](testing/user-study.md)。

## 現場流程（建議 4 分鐘）

1. 事前安裝最新版，關閉原本 App，執行 MarVoiReflex-Presentation.cmd。等待「索引就緒」及模型就緒。示範資料是 3 張不具語意檔名的圖片、一份 PDF、一份 CSV、一份 TXT，全部由程式生成，並未讀取個人磁碟。
2. 通話中說「幫我找昨天下載的 PDF」，顯示原始檔案並點擊下載或開啟。日期依最後修改時間。若語音辨識低信心則重說。
3. 通話中說「幫我找汽車的照片」，等待實際模型完成辨識，展示縮圖與原始圖片下載。不宣稱即時辨識。若需縮短現場等待，可先以展示模式進行排練，但應明確說明快取狀態。
4. 說「找出紅色背景的圖片」驗證非檔名式搜尋。輸入「找出所有密碼檔案」展示安全拒絕。展示模式不允許擴張至本機磁碟。
5. 若要展示搬移流程，另於一般模式使用工作區合成素材，執行預覽、確認與結果核對；外部原始檔案仍為唯讀。

## 重複測試

使用獨立 Windows x64 測試機，已安裝 App 與模型；先關閉所有 MarVoiReflex 程式。開發環境 Python 3.12，安裝 psutil、playwright，系統須有 Microsoft Edge。測試程式會建立獨立展示 session，並留下 JSON 和 PNG 截圖，不掃描個人資料。範例：

    python scripts/test_presentation.py --app "C:/path/to/MarVoiReflex.exe" --out "C:/path/to/test-evidence"

記錄欄位：實際輸入、預期與實際選檔、是否通過、伺服器端請求耗時、服務啟動耗時、單次程序樹 RSS 快照。P14 驗證真實瀏覽器縮圖和下載內容，並核對原始素材雜湊。RSS 不是峰值，也不等同系統總記憶體或 8GB 實機結果。

## 目前限制

實際真人麥克風、現場噪音、8GB 實機及完整 50 組研究案例仍待驗證。標準安裝使用 E2B Vision、Whisper Small、SAPI；Moonshine、E4B、OCR 與向量模型為另行配置的選用功能，不能描述成已全部隨標準版交付。合成素材的辨識結果不代表真實商業圖庫的準確率。
