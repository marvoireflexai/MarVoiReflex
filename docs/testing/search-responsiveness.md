# 圖片搜尋反應速度驗證

本測試以 v0.3.2 的六份合成素材為基準，另在 v0.3.3 的相同展示資料上量測實際本機推論。測量三張圖片的首次搜尋、同工作階段重複查詢、紅色背景與黃色花朵查詢、進度與取消、重試及原檔下載。

測試命令（先關閉 MarVoiReflex，於 Windows Python 3.12 開發環境安裝 psutil、playwright，系統需有 Edge）：

    python scripts/test_responsive_search.py --app "C:/path/to/MarVoiReflex.exe" --out "C:/path/to/test-evidence"

模型改為只產生結構化 yes/no/uncertain 判定。所有 yes 均仍須第二次獨立判定；不一致列為需確認，不虛構可見證據或信心分數。結果卡提供圖片縮圖供使用者檢查。

查詢快取以內容 SHA-256、去除尾端一般標點的查詢與判定版本為基礎。工作階段內可重用確定或不確定的有效判定，不確定不計為命中。模型錯誤及未完成複核不寫入快取。外部原始檔的圖片判斷只存在記憶體；撤銷或變更授權清除，工作區確定結果則可沿用原有本機 SQLite 快取。輸入「清除圖片辨識快取」可清除當前工作階段的記憶體快取（不清除工作區已保存的確定結果）。

搜尋進度以已處理候選數量為準，而非推估百分比；停止請求僅取消圖片搜尋，待正在進行的模型請求回傳後停止，不終止整個模型或取消已確認的檔案搬移。所有檔案仍按原授權重新驗證。

此測試為六份合成資料及三個圖片查詢，不代表實際商業素材準確率。計時為單次 API 實際請求，不含口語辨識及 TTS；本輪未重驗實體麥克風、8GB RAM 或跨裝置全磁碟效能。原訂 50 組研究案例及真人使用者研究不因本測試而完成。
