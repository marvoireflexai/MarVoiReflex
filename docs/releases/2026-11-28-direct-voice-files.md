# MarVoiReflex v0.3.1｜語音交辦與檔案直接取得

**[Windows 安裝／更新工具](https://github.com/marvoireflexai/MarVoiReflex/releases/download/v0.3.1-direct-voice-20261128/MarVoiReflex-Download-Windows.cmd)**

既有 v0.3.0 標準安裝只需約 21 MB 更新包；保留 Gemma 權重與既有資料。安裝工具沿用 r2 短路徑，支援已驗證的舊版下載快取。

## 使用體驗

- 通話結束一段指令後，自動交由任務控制器處理，不轉填文字輸入框，不需再按送出，也不自動掛斷。聊天模式中明確的檔案指令也會自動路由。
- 搜尋、列出、支援的讀取和圖片辨識直接回傳結果。低信心辨識以語音請使用者重說，尚不執行該任務；工作區搬移仍須畫面確認。外部原檔仍為唯讀範圍。
- 通話及任務頁直接顯示檔案結果卡，可依支援格式開啟原檔、下載原始位元組、預覽圖片或文字。無須再手動搜尋資料夾。
- 單檔下載上限 128 MiB；較大檔案可用支援格式的原檔開啟功能。圖片預覽為 JPEG 縮圖，下載保持原始格式與內容。純文字預覽限 TXT、MD、CSV 及 64 KiB；圖片預覽限 JPEG、PNG、WebP 及 32 MiB。
- 結果以工作階段 ID 存取；伺服器重新檢查授權、原始路徑及檔案狀態，工作區下載另核對內容雜湊。拒絕任意路徑、失效 ID 與未授權結果。開啟原檔由使用者明確點選，交給 Windows 檔案關聯應用程式。
- 不擴大本機檔案權限、不啟用雲端傳輸、不自動刪除、移動或覆寫原始檔案。

## 驗證

本機原檔取得 11/11 項整合測試通過；更新後 Windows EXE 的語音交辦與通話畫面直接取得檔案 6/6 項測試通過。瀏覽器下載檔與原檔位元組一致，無 JavaScript 錯誤。低信心辨識、安全結果 ID 與撤銷授權另經單元測試。隔離 Windows 32GB 開發環境與封裝測試證據見 [驗證結果](../evidence/direct-voice-files-20261128.json)。測試使用合成語音、瀏覽器模擬麥克風及合成素材，不等同真人語音、使用者實際電腦或其他硬體驗收。原檔開啟測試確認 Windows API 目標路徑，未驗證各檔案關聯應用程式的實際開啟畫面。
