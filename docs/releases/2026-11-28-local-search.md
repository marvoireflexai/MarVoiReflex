# MarVoiReflex v0.3.0｜本機檔案搜尋

## 免匯入操作

1. 關閉原版本，執行 [Windows 一鍵安裝／更新工具](https://github.com/marvoireflexai/MarVoiReflex/releases/download/v0.3.0-local-search-20261128/MarVoiReflex-Download-Windows.cmd)。
2. 進入任務頁，按「啟用個人檔案搜尋」；若需要更廣範圍，確認「擴及本機磁碟」。
3. 索引建立後，直接輸入「幫我找昨天下載的 PDF」、「找出有汽車的照片」或「找出檔名包含『活動』的檔案」。
4. 結果顯示原始路徑，可前往檔案所在資料夾；TXT、MD、CSV 可直接預覽。選擇「停用並清除索引」即可撤回授權。

既有 v0.2.0 或 v0.2.1 標準安裝僅需約 20.97 MB 增量包；模型和使用者資料保留。首次安裝約 5.06 GB。此版本不要求 Windows 管理員權限。

## 安全與範圍

- 啟用前不掃描個人資料夾或磁碟；個人範圍包含目前使用者資料夾及 Windows 已知資料夾，磁碟範圍擴及可讀取的本機固定與外接磁碟。
- 遵守目前帳號權限，排除網路位置、系統目錄、其他標準使用者設定檔目錄、隱藏／離線／重新解析路徑、常見敏感名稱及非支援檔案類型。名稱排除不能保證辨識所有敏感內容。
- SQLite 只索引檔名、路徑、類型、大小及最後修改時間。按需求讀取文字或圖片；不自動上傳資料。結果 ID 僅在本次工作階段有效，讀取前重新驗證路徑及檔案狀態。
- 授權範圍以唯讀搜尋為主，外部檔案不交由 MCP 任意操作。原工作區分類仍可在明確指定並確認後使用。
- 本版採有上限的目錄掃描（最多 500,000 個項目或 120 秒），支援索引狀態、手動更新及分頁；未完成時明示部分結果。尚未實作 Windows Search API、NTFS MFT、USN Journal、即時變動追蹤或 FTS5。
- 圖片內容搜尋每批 12 張；其他文件格式目前僅搜尋中繼資料。日期依最後修改時間，不代表原始建立或下載時間。索引撤銷會停止掃描、清除索引及結果，不刪除原始檔案。
- 預設 Windows 封裝保留 E2B Vision、Whisper 和 SAPI；Moonshine、OCR、EmbeddingGemma 及進階 E4B 的選用配置仍屬開發環境或另行配置功能，未隨標準安裝包提供全部權重。

## 驗證

Windows x64 32GB 桌機，隔離測試資料夾的 9 項本機搜尋驗收通過，包含一次性授權、原始檔案搜尋、文字預覽、日期和資料夾篩選、分頁、實際 E2B 圖片辨識、敏感位置排除、過期結果拒絕和撤銷索引。未掃描實際私人資料。

更新後的 Windows EXE 10 項回歸檢查通過，含授權介面、未授權不掃描、既有工作區搜尋、預覽與確認搬移。v0.2.0 和 v0.2.1 的隔離更新及重複更新皆通過；尚未驗收實際全磁碟索引、8GB 記憶體裝置及不同硬體環境。
