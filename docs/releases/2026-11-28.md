## 驗證狀態

已於 Windows 32GB 桌機完成模型、視覺搜尋模組、App API、EXE 編譯及 ZIP 還原校驗。包裝包含 22,161 個檔案。重新解壓的 Windows EXE（未覆寫模型設定）經 Microsoft Edge UI 自動化測試通過：介面渲染、聊天、匯入 3 張圖片、依圖像內容找出檔名錯置的汽車圖片、預覽 3 個檔案、畫面確認、實際搬移及逐檔 SHA-256 驗證，無 JavaScript 錯誤。詳見[完整 UI 驗證結果](../evidence/gemma4-e2b-frozen-ui-20261128.json)。8GB 記憶體裝置、其他硬體配置及受管理的 Windows 環境尚未完成相容性驗證，實體麥克風亦尚未完成測試。

新版預設使用本機瀏覽器 UI，原生 WebView2 視窗為選用模式。圖片搜尋僅涵蓋已匯入的圖片、單次至多 40 張、唯讀；不自動搬移。分類仍須畫面確認。
