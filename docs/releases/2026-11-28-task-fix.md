# MarVoiReflex v0.2.1｜任務輸入與辨識修正版

## 更新方式

關閉既有 MarVoiReflex，下載並執行 [Windows 一鍵安裝／更新工具](https://github.com/marvoireflexai/MarVoiReflex/releases/download/v0.2.1-task-fix-20261128/MarVoiReflex-Download-Windows.cmd)。既有 v0.2.0 標準安裝只需下載約 20.92 MB 修正包，校驗及更新 4 個程式檔案，保留原模型、素材及使用者資料。首次安裝會自動取得原始完整 App、官方權重與修正包，下載總量約 5.06 GB。

## 功能變更

- 任務側欄直接進入操作頁；支援送出按鈕、Enter 與中文輸入法組字。
- 顯示本機模型準備、任務處理及錯誤狀態；服務忙碌時保留輸入並可重試。
- 基本明確的素材列表、搜尋及分類預覽優先採用可驗證規則。
- 圖片縮放上限提高至 1280 像素，視覺 token 上限從 280 提高至 560；對初次符合結果再複核，不一致時標示需確認。
- 語音辨識改用 5-beam 解碼、音量正規化與較長停句判定；語音任務先呈現可編輯轉錄，由使用者送出。
- 分類仍須由使用者確認，保留原有檔案範圍及完整性校驗。

## 驗證

Windows x64 32GB 桌機完成原始碼及更新後 EXE 的 9 項 UI 測試，各 9/9 通過，含按鍵送出、受控忙碌回應、素材匯入、圖片內容搜尋、預覽及確認搬移；無 JavaScript 錯誤。3 組 Windows SAPI 合成中文指令轉錄，忽略標點後字元錯誤率為 0%，均進入轉錄審閱而非直接執行。隔離的既有安裝更新、資料保留、4 檔 SHA-256 校驗與重複更新均通過。

這些結果僅代表受控測試；尚未完成真實麥克風、環境噪音、大量真實圖片及 8GB 記憶體跨裝置驗證。模型仍為 Gemma 4 E2B Vision；視覺複核可能增加 CPU 處理時間。
